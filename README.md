# Check AppStore

Небольшая утилита для проверки, какие приложения из вашей выгрузки iMazing доступны или недоступны в выбранной стране App Store.

Проект создан для ситуации, когда при переносе со старого iPhone на новый некоторые любимые приложения больше нельзя скачать из App Store. Проверка позволяет заранее определить такие приложения и сохранить их IPA с помощью iMazing, чтобы затем перенести их на новый iPhone.

## Как это работает

1. Выгрузите список приложений со старого iPhone через **iMazing** в формате CSV.
2. Запустите `Check AppStore`.
3. Введите код страны App Store, например:

   * `ru` — Россия
   * `tr` — Турция
   * `us` — США
   * или код любой другой страны.
4. Выберите выгруженный из iMazing CSV-файл.
5. Программа проверит каждое приложение по его **Store ID**.
6. В терминале будет показано:

   * сколько приложений проверено;
   * сколько доступно в выбранной стране;
   * какие приложения отсутствуют;
   * какие приложения не удалось проверить.

Программа **не создаёт дополнительных CSV-файлов** — результат выводится непосредственно в терминал.

## Что понадобится

* Python 3
* iMazing
* старый iPhone с установленными приложениями
* подключение к интернету

## Установка Python

Если Python ещё не установлен, скачайте его с официального сайта:

https://www.python.org/downloads/

После установки проверьте в Terminal:

```bash
python3 --version
```

## Установка Check AppStore

Склонируйте репозиторий:

```bash
git clone https://github.com/envifood/check-appstore.git
cd check-appstore
```

Установите необходимую библиотеку:

```bash
pip3 install requests
```

## Запуск

Запустите программу:

```bash
python3 check_appstore.py
```

Сначала программа попросит указать страну:

```text
Введите код страны App Store (например: ru, tr, us):
```

После этого откроется окно выбора CSV-файла из iMazing.

Выберите выгрузку приложений со старого iPhone и дождитесь окончания проверки.

## Подготовка приложений к переносу

После проверки можно посмотреть список приложений, которых нет в выбранном App Store.

Для приложений, которые вы хотите сохранить, можно заранее получить IPA через iMazing и использовать сохранённые файлы при переносе на новый iPhone.

### Важно

Check AppStore **не скачивает IPA и не устанавливает приложения**. Он только проверяет доступность приложений в выбранном App Store по их Store ID.
